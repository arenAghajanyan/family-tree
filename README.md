# Family Tree

A family tree builder that runs entirely in your browser — one HTML file, no install, no server, no account.

**Live:** https://arenaghajanyan.github.io/family-tree/

## Use it

Open `family-tree.html` in any modern browser, or use the live link above.

- Add people, partners, parents and children, and see the tree drawn around a main person.
- **Photos** for each person, shown on the tree and on printed charts.
- **Multiple partners** — marriages, divorces, separations, engagements and other relationships, each with its own dates. Children are linked to the right partner, and half-siblings show up automatically.
- **More details** per person: nicknames, occupation, where they lived, burial place, notes, and sources.
- **How related?** — names the relationship between any two people (second cousin once removed, half-brother, mother-in-law, stepson…). Each person's panel also shows how they're related to the main person.
- **Birthdays** — upcoming birthdays, wedding anniversaries and remembrance days.
- **Charts & print** — whole-family, ancestor and descendant charts. Save as PNG or SVG, or print / save as PDF. Optionally hide living people's details before sharing.
- **Undo / redo** for every change (⌘/Ctrl + Z).
- Search the people list, zoom the tree, and switch light/dark with your system theme.
- **Save backup** downloads a `.json` file (including photos) you can load later with **Open file…**.
- **Export GEDCOM** produces a `.ged` file that works with Gramps, Ancestry, MyHeritage, FamilySearch and others. GEDCOM files can also be imported.

## Where your data lives

Everything is stored in your own browser on your own device. Nothing is uploaded anywhere. Clearing site data or switching browsers will lose it, so use **Save backup** regularly.

Backup and export files (`.json`, `.ged`) are listed in `.gitignore` so personal family data isn't committed by accident.
